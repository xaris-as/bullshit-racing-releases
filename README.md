# Bullshit Racing · releases

**EL** · Εδώ βγαίνουν οι εκδόσεις του Bullshit Racing. Κατέβασε τον launcher από τα
[Releases](https://github.com/xaris-as/bullshit-racing-releases/releases/latest) (`BullshitRacingSetup.exe`), τρέξ' τον μία φορά και από εκεί
και πέρα κατεβάζει μόνος του κάθε ενημέρωση. Τα Windows μπορεί να δείξουν μπλε προειδοποίηση SmartScreen (ο launcher
δεν έχει ψηφιακή υπογραφή): «Περισσότερες πληροφορίες» → «Εκτέλεση οπωσδήποτε».

**EN** · Bullshit Racing releases. Download the launcher from [Releases](https://github.com/xaris-as/bullshit-racing-releases/releases/latest)
(`BullshitRacingSetup.exe`), run it once, and it keeps the game up to date by itself. Windows SmartScreen may warn
(the launcher is not code-signed): "More info" -> "Run anyway".

Bugs: open an [issue](https://github.com/xaris-as/bullshit-racing-releases/issues) (the launcher has a "Report a bug" button that fills in the
versions for you).

---
Layout (read by the launcher): `channel.json` (latest version + patch notes), `game/manifests/<version>.json`
(files + SHA-256), `game/blobs/` (file contents by hash). Original game, all rights reserved by its authors.
